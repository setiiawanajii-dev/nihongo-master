# Perbaikan B04 — aktivitas lintas tengah malam

Flashcard, grammar, review, dan quiz kini mencatat waktu aktif berdasarkan tanggal lokal setiap jawaban. Satu sesi yang melewati tengah malam dapat muncul pada dua hari, tetapi total sesi tetap satu dan waktu tidak digandakan. Ini pencatatan berdasarkan waktu jawaban, bukan pelacakan setiap detik saat pengguna membaca.

Data lama disesuaikan sekali dari riwayat jawaban yang tersimpan. Jika bukti waktu tidak lengkap, durasi yang tidak dapat dipetakan tetap di tanggal semula; tidak dibuat aktivitas baru tanpa bukti. Mastery, materi, dan hasil quiz tidak dihapus.

Verifikasi: delapan tes B02–B04 lulus, mencakup pukul 23.59 dan 00.01 di Asia/Tokyo pada empat alur belajar, duplikasi pengiriman jawaban, streak, jumlah sesi, penyesuaian data lama, serta refresh. Build produksi berhasil.

Paket ini mencakup B02, B03, dan B04. Ekstrak dan unggah src, tests, serta dokumen pembaruan ke root repository GitHub yang sama. Pertahankan file lain. Setelah deployment Vercel berhasil, tutup tab aplikasi lama dan buka ulang untuk memperbarui penyimpanan lokal.
